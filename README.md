# HashPairCheck-
HashPairCheck 是一款基于 WPF 开发的轻量化 Windows 文件哈希校验工具，兼容 Win10、Win11 系统。工具操作简单，支持文件拖拽与手动选择两种导入方式，可快速计算 MD5、SHA256 等常用哈希值，支持文件哈希比对，有效校验文件完整性，防止文件篡改、传输损坏。  程序采用单文件发布，免安装、无需额外配置运行环境，双击即可启动，适用于日常文件核验、资源校验、备份比对等场景。本项目开源免费，遵循 MIT 协议，代码简洁易懂，适合桌面开发入门学习。  目前程序暂无数字签名，但兼容性良好。本人在安全卫士全开、虚拟机环境下测试运行，无风险报错，设备均可正常稳定使用。
